VR Climate Simulator
====================

A VR application in which you live a short day in a virtual apartment and take
small everyday decisions with an environmental impact. Your choices change the
weather, the music and the radio bulletin of the virtual world.

Authors: Alessandro Tomaiuolo, Gianluca Di Giacomo

REQUIREMENTS
------------
- Windows 64-bit PC
- An OpenXR-compatible VR headset, connected and with its OpenXR runtime set
  as active (without a headset the application cannot start)

HOW TO RUN
----------
1. Unzip the whole folder (do not move the .exe out of it).
2. Connect and turn on the headset.
3. Run VRClimateChange.exe.

HOW TO PLAY
-----------
1. Watch the introductory video.
2. Enter your name with the virtual keyboard (point with the ray and press
   the trigger), then confirm.
3. Complete the six tasks in order: light, recycling, breakfast, thermostat,
   going to work, dinner. The current task is shown in the HUD.

Controls
- Thumbstick: move / snap turn
- Grip button: grab objects, press switches, turn knobs
- Trigger button: use (e.g. squeeze a bottle or an orange)
- Touch buttons and panels with your hand (poke)

LOGS
----
Every session is recorded in Logs/results_log.csv (semicolon-separated,
next to the executable). The file is created automatically on first run.

CREDITS
